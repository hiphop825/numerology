# 八字排盤系統

這是一個基於Python的八字排盤系統，可以根據出生日期時間計算出完整的八字（年柱、月柱、日柱、時柱）。

## 功能特色

- 計算四柱八字（年柱、月柱、日柱、時柱）
- 顯示對應的生肖
- 顯示天干地支的五行屬性
- 支援跨年度計算

## 使用方法

### 方法一：直接運行（互動模式）

```bash
python bazi_calculator.py
```

按照提示輸入出生年、月、日、時，系統將自動計算並顯示八字排盤結果。

### 方法二：測試範例

查看預設的測試案例：

```bash
python test_bazi.py
```

## 技術說明

### 四柱計算方式

1. **年柱**：根據出生年份計算天干地支
2. **月柱**：根據年干和月份推算（正月為寅月）
3. **日柱**：以2024年1月1日為基準點推算
4. **時柱**：根據日干和小時數推算

### 五行對應

- 天干五行：
  - 甲、乙 → 木
  - 丙、丁 → 火
  - 戊、己 → 土
  - 庚、辛 → 金
  - 壬、癸 → 水

- 地支五行：
  - 寅、卯 → 木
  - 巳、午 → 火
  - 辰、戌、丑、未 → 土
  - 申、酉 → 金
  - 亥、子 → 水

## 文件說明

- `README.md`：說明文件

## 注意事項

1. 時柱計算採用傳統的十二時辰制（子時為23-1點）
2. 本系統採用簡化算法，實際應用中可能需要考慮節氣變化等更複雜因素
3. 出生時間以24小時制輸入
